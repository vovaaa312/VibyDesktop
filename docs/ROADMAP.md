Этап 3 — сохранность данных (десктоп: 1.1.0)
- [x] Экспорт/импорт медиатеки: «Настройки → Резервная копия» — JSON (плейлисты, порядок, связи с YouTube,
       оформление и EQ, без cookies/токенов/абсолютных путей) или zip вместе с музыкой; импорт сливается
       с текущей медиатекой без дублей. Формат viby-library v1 — его же стоит реализовать в Android.
- [x] Экспорт плейлистов: меню плейлиста → M3U8 (для других плееров) или JSON (Viby).
- [x] Выбираемая папка («Настройки → Папка с музыкой»): при смене — перенести музыку (и между дисками),
       найти уже лежащую в новой папке или оставить старые треки на месте.
- [x] Перепривязка файлов: по имени файла, затем по ID YouTube из тегов (purl/comment); файлы вне
       медиатеки добавляются в плейлист по имени папки; недостающие можно скачать заново на свои места.
- [x] Проверка свободного места до загрузки (200 МБ + ~48 КБ на секунду трека → «Недостаточно свободного места»).
- [x] Очистка временных и оборванных файлов (.part, фрагменты, промежуточные), кроме папок активных загрузок.
- [x] Экран «Хранилище»: размер медиатеки и плейлистов, свободное место, потерянные файлы,
       файлы вне медиатеки (добавить/удалить), временные файлы.

- [x] Фильтр «Не загружено» / «С ошибкой» / «Нет файла»: кнопки над списком, появляются, когда есть что показать.

- [x] Сортировка (5 режимов) и фильтр запоминаются для каждого плейлиста; очередь идёт в порядке выбранной сортировки.

Что пока не стоит делать (без изменений)
- Собственную «нейросеть рекомендаций».
- Полноценную облачную синхронизацию между устройствами.
- Spotify Connect-аналог.
- Скачивание первых 2–3 секунд каждого трека параллельно.
- Chromecast до стабилизации обычного воспроизведения.
- Большую переделку интерфейса одновременно с рефакторингом загрузок.

Опционально — ускорение загрузки
- [ ] Замерить отдельно получение данных YouTube, передачу аудио, конвертацию FFmpeg и встраивание
      обложки/тегов; после замеров выбрать безопасное ускорение без роста ошибок и блокировок YouTube.

Есть в десктопе сверх гайдлайна (кандидаты в Android для паритета)
- Перетаскивание приоритета загрузок: верхняя задача/трек качается первой, можно поднять трек выше скачиваемого.
- Импорт аудиофайлов с компьютера в плейлист.
- Цветовые темы (Viby / Spotify / YouTube).
- Громкость колесом мыши, обработка ошибок с «Подробнее» и авто-повтором потока при 403.
- Пометка «файл не найден» у скачанных треков без файла, «Скачать заново» из меню трека.
- Приоритет процессов: загрузки ниже обычного, воспроизведение выше.

Нумерация версий десктопа (принято)
- Формат MAJOR.MINOR.PATCH (SemVer), без четвёртой цифры.
- MINOR = завершённый этап гайдлайна, PATCH = исправления и мелкие улучшения внутри этапа.
- Этапы 1–2 уже покрыты линейкой 1.0.x; ближайший патч 1.0.3 — обработка ошибок.
- Этап 3 → 1.1.0, этап 4 → 1.2.0, этап 5 → 1.3.0 (если этап крупный — промежуточные 1.x.0 по частям).
- MAJOR (2.0.0) — только при несовместимых изменениях: формат БД/настроек без миграции и т.п.
